# dsh-team-limits

**调整 Agent Team 的任务数上限，并决定新会话是否默认开启团队协作。**

> [English](README.en.md) | 中文

## 什么时候用得上

- 任务板上限 256 条，任务一多就要排队
- 不想每个新会话都手动去打开团队协作
- 想回出厂值，但不想翻配置文件

## 安装

1. 打开 设置 → 插件 → 市场，搜索 `dsh-team-limits`
2. 点安装
3. **完全退出 DSH，再重新打开**

> 如果你的 DSH 是 0.2.1（团队功能还叫「实验性插件」的那个版本），请装 `dsh-team-limits@1.3.9`。2.x 是按 0.2.2 的新设置项写的：0.2.2 把团队功能转正的同时，把「成员数」「单条消息大小」「清理超时」这三项删掉了，只留下任务数和一个默认开关，所以 2.x 在 0.2.1 上会被拦住，1.3.9 在 0.2.2 及以上也不适用。

需要 DSH 0.2.2 或更新。

## 在哪里改

设置 → 插件 → 已安装 → **团队限额**：

| 设置项 | 出厂默认 | 含义 |
| --- | --- | --- |
| 任务数上限 | 256 | 共享任务板上同时保留多少条任务 |
| 默认开启团队协作 | 关 | 新会话是否自动启用团队协作 |

改完点「保存」才生效，想反悔点「放弃更改」。某个字段一旦偏离出厂值，旁边就会出现「恢复默认」。

## 注意

- 这些设置存在你本机的 DSH 配置里，不属于这个插件。
- 人数、单条消息大小与清理超时现在由子代理的设置负责，不在这里。
- 提高任务数不是免费的：任务越多，同时跑的模型会话越多，token 也越多。按需调。
- **「默认开启团队协作」对新建对话生效**，包括从第一条消息打开的对话；重开旧对话保留你上次的选择。

## 常见问题

**装完没看到页面？** 没有完全退出 DSH。从托盘退出再打开。

**改了没反应？** 改动要点「保存」才写入；保存后约 1.5 秒按正常加载流程生效。

**想全部回到出厂值？** 每个字段点一次「恢复默认」。

## 卸载

在插件面板里停用或卸载。想把数字也恢复，请先在页面上点「恢复默认」。
