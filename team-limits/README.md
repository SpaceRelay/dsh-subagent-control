# dsh-team-limits

Agent Team 那四个上限，改成能填的数字。

默认最多 16 个队友，任务一多就排队，子代理回传的长消息还会被截断。想调一调，以前只能去翻配置文件，还得改对地方。现在这四个数字就摆在插件页里，边填边生效。

装的时候需要完全退出 DSH 再打开。这个插件带一个设置页，界面在启动时组装，只刷新页面是出不来的。

装完在 设置 → 插件 → 已安装 → 团队限额 里能看到四个输入框：

| 设置项 | 出厂默认 | 本页初始值 |
| --- | --- | --- |
| 最多成员数 | 16 | 32 |
| 最多任务数 | 256 | 512 |
| 单条消息上限（字节） | 65536 | 131072 |
| 清理超时（毫秒） | 5000 | 5000 |

边输边存，没有保存按钮。某个字段一旦和出厂值不一样，旁边就会出现「恢复默认」。

有两点值得先知道。

数值是存在你 profile 的补丁里的，所以卸载这个插件不会把它们变回出厂值。想要回默认，先在页面上点「恢复默认」，再卸载。

提高上限不是免费的。队友多一个，就多一条并发的模型会话，每个都在花 token、占一个会话目录，按需要调。

装完没看到页面？多半是没有完全退出 DSH，从托盘退出再打开。

改了没反应？页面上是即时写入、按正常加载流程生效的；如果装的还是旧版本，重装一次。

想全部回到出厂值？每个字段点一次「恢复默认」。

纯终端里的 DSH 不显示这个页面，但限额照样生效。

卸载就是在插件面板里停用或卸载。想连数字一起恢复，先在页面上点「恢复默认」。

实现方式、四个字段的来源与写入路径，在 [docs/implementation.md](https://github.com/SpaceRelay/dsh-subagent-control/blob/main/team-limits/docs/implementation.md)。
