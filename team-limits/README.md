# dsh-team-limits

**在插件页里调整 Agent Team 的人数、任务数、单条消息大小与清理超时。**

> [English](README.en.md) | 中文

## 什么时候用得上

- 默认最多 16 个队友，队伍不够用
- 任务一多就排队（默认 256 条）
- 子代理回传的长消息被截断（默认 64 KB）
- 想回出厂值，但不想去翻配置文件

## 安装

1. 打开 设置 → 插件 → 市场，搜索 `dsh-team-limits`
2. 点安装
3. **完全退出 DSH，再重新打开**

## 在哪里改

设置 → 插件 → 已安装 → **团队限额**，四个数字框：

| 设置项 | 出厂默认 | 本页初始值 |
| --- | --- | --- |
| 最多成员数 | 16 | **32** |
| 最多任务数 | 256 | **512** |
| 单条消息上限（字节） | 65536 | **131072** |
| 清理超时（毫秒） | 5000 | 5000 |

改动边输边存，没有保存按钮。某个字段一旦偏离出厂值，旁边就会出现「恢复默认」。

## 注意

- **数值存在 profile 的补丁层里。** 卸载本插件不会把它们变回出厂值，要恢复请先在页面上点「恢复默认」。
- **提高上限不是免费的。** 队友更多意味着更多并发的模型会话，每个都消耗 token 和一个会话目录，按需要调。
- 纯终端的 profile 不显示这个页面，但限额照样生效。

## 常见问题

**装完没看到页面？** 没有完全退出 DSH。从托盘退出再打开。

**改了没反应？** 页面上的改动会即时写入，按正常加载流程生效；如果插件是旧版本，重装一次。

**想全部回到出厂值？** 每个字段点一次「恢复默认」。

## 卸载

在插件面板里停用或卸载。想把数字也恢复，请先在页面上点「恢复默认」。
