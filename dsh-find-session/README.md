# dsh-find-session

对话里按 `Ctrl+F` 找到任何一句话，或者一次搜完所有会话。

DSH 的对话是分页加载的，浏览器自带的页内查找只认得已经渲染出来的那部分，早先的轮次它根本看不见。这个插件把查找做进对话里：命中直接高亮，可以前后跳；也可以切到「全局」，把所有会话一起搜。

安装要完全退出 DSH 再打开，插件是启动时组装的，只刷新页面不会生效。也可以在插件管理器里按包名 `dsh-find-session` 从 npm 装。

怎么用：

| 想做的事 | 怎么做 |
| --- | --- |
| 在当前对话里找 | `Ctrl+F`，边输边高亮，`Enter` 下一个、`Shift+Enter` 上一个 |
| 在所有会话里找 | `Ctrl+Shift+F`，或者左侧栏的「查找」图标，切到「全局」 |
| 先看看这条是不是我要的 | 点结果展开预览（前后各两条），再决定要不要跳 |
| 跳过去 | 点「打开」，切到那个会话并定位到那一轮 |
| 一边看对话一边翻结果 | 查找页右上角「停靠到右侧栏」 |
| 关掉查找条 | `Esc` |

快捷键可以在 设置 → 快捷键 里改。

设置 → 查找，有三个选项：默认匹配方式（子串 / 整词 / 正则）、默认内容范围（正文、工具调用、思考过程，三档独立开关，默认只搜正文）、单次结果上限。

装完了没变化？没有完全退出 DSH，从托盘退出后重新打开，只刷新页面不够。

当前对话里只搜到一部分？会话内查找只高亮已经渲染出来的内容。跳到更早的命中时插件会先加载历史，但一次加载多少由 DSH 决定。

全局结果被截断了？单次扫描有预算（默认 3 万文本块），把时间或工作区收窄一点就能搜全。

中文两个字能搜吗？能。插件不依赖分词，直接按字符做子串匹配，`会话` 能搜到「我们来做会话上下文关键词查找」。

它只读本地会话日志，不联网、不上传任何内容，也不改会话、不改 profile。全局扫描默认最多读 3 万文本块，超出会提示收窄条件；结果有缓存，同一个查询不会重扫。

卸载：设置 → 插件 → 已安装 → `dsh-find-session` → 停用或卸载，然后重启 DSH。

实现结构、`cordis.patch.yml` 的配置覆盖、测试与验收记录，在 [docs/implementation.md](https://github.com/SpaceRelay/dsh-subagent-control/blob/main/dsh-find-session/docs/implementation.md)。
