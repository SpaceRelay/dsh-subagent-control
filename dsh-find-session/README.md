# dsh-find-session

**对话里按 `Ctrl+F` 找到任何一句话，或者一次搜完所有会话。**

DSH 的对话是分页加载的，浏览器自带的页内查找只能看到已经渲染出来的部分，早先的轮次搜不到。这个插件把查找做进对话里：命中直接高亮、可以前后跳；也可以切到「全局」，把所有会话一起搜。

> [English](README.en.md) | 中文

## 什么时候用得上

- 长对话翻了半天，想找「上次那个方案是在哪一步定的」
- 记得聊过某个报错，但记不清是哪个会话——搜一次全找出来
- 只想看自己问过什么，不想被工具输出淹没

## 安装

1. 打开 设置 → 插件 → 市场，搜索 `dsh-find-session`
2. 点安装
3. **完全退出 DSH，再重新打开**

最后一步不能省：插件在启动时组装，只刷新页面不会生效。

也可以按包名 `dsh-find-session` 从 npm 安装（插件管理器的「从 npm 安装」）。

## 怎么用

| 想做的事 | 怎么做 |
| --- | --- |
| 在当前对话里找 | `Ctrl+F`，边输边高亮，`Enter` 下一个、`Shift+Enter` 上一个 |
| 在所有会话里找 | `Ctrl+Shift+F`，或左侧栏的「查找」图标，切到「全局」 |
| 看这一条是不是我要的 | 点结果展开预览（前后各两条），再决定要不要跳 |
| 跳过去 | 点「打开」，切到那个会话并定位到那一轮 |
| 一边看对话一边翻结果 | 查找页右上角「停靠到右侧栏」 |
| 关掉查找条 | `Esc` |

快捷键可以在 设置 → 快捷键 里改。

## 设置

设置 → 查找：

- **默认匹配方式**：子串 / 整词 / 正则
- **默认内容范围**：正文、工具调用、思考过程，三档独立开关（默认只搜正文）
- **单次结果上限**

## 常见问题

**装完了没变化？** 没有完全退出 DSH。从托盘退出后重新打开，只刷新页面不够。

**当前对话里只搜到一部分？** 会话内查找只高亮已经渲染出来的内容。跳到更早的命中时插件会先加载历史，但一次加载多少由 DSH 决定。

**全局结果被截断了？** 单次扫描有预算（默认 3 万文本块）。把时间或工作区收窄一点，就能搜全。

**中文两个字能搜吗？** 能。插件不依赖分词，直接按字符做子串匹配，`会话` 能搜到「我们来做会话上下文关键词查找」。

## 隐私与开销

- 只读本地会话日志，不联网、不上传任何内容
- 不修改会话、不改 profile、不写设置文档
- 全局扫描默认最多读 3 万文本块，超出会提示收窄条件；结果有缓存，同一个查询不会重扫

## 卸载

设置 → 插件 → 已安装 → `dsh-find-session` → 停用或卸载，然后重启 DSH。
